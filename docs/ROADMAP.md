# これから（案）

方針：**ホームは入口と軽い一覧だけ**。重い再生・編集は各 Hatch アプリ（Music・Movie・Book・Photo）とテレビの機能に任せる。
4T-C65DQ2 は 2021 年の Android TV で CPU・メモリが控えめ。動画はテレビの映像デコーダー（ハードウェア）で再生し、CPU で絵を作らない。

| 版 | 中身 | 見込み |
| --- | --- | --- |
| 0.1 | ホーム・テレビの入口・時計・天気・予定（iCal）・すきなアプリ・子どもモード・自動更新（ハブ）・ADB の窓口 | 済み（実機は未確認） |
| 0.2 | ADB で調べた地デジ・BS・録画の入口を既定にする。入口の名前の付け替えを画面から。既定のホームに切り替え | ADB の結果しだい |
| 0.3 | **USB HDD**（録画用とは別。exFAT）の動画・音楽・写真を一覧して、テレビの再生アプリ（または Movie）で開く。「続きから」 | ○ 録画用 HDD はテレビ専用の形式なので読めない |
| 0.4 | **NAS（Tailscale）**：NAS の状態、Music・Movie・Book・Photo の棚（spec の `/shelf`）を並べ、押すとそのアプリで再生。**NAS のキャッシュ**：選んだフォルダを夜に USB HDD へ写しておき、NAS が見えないときもそこから再生 | ○ Tailscale はテレビ用の公式アプリ。NAS のログインは設定のハブで預かる |
| 0.5 | **SwitchBot**：シーン（「おやすみ」など）のタイル。クラウド API（トークンと秘密は ADB の SET_SECRET で） | ○ 軽い |
| 0.6 | **家族とはなす**：顔写真のタイルを押すと相手を呼ぶ。第一候補は Synology Chat Plus／Meet（β）。テレビにアプリが入るか・USB カメラとマイクが使えるか・相手を指定して開けるかを先に ADB で確かめる。だめなら NAS の Jitsi などへ | △ いちばん不確か。着信は相手アプリが前に出せるかしだい |
| 0.7 | **Tapo カメラ**：小さな窓（ピクチャー・イン・ピクチャー）で見る。カメラの低画質の映像（stream2、640×360・H.264）を RTSP で受けて、ハードウェアで再生 | ○ 小窓 1 つなら CPU は軽い。2 つ以上・高画質は様子を見る |
| 0.8 | **事務作業**（BT キーボード）：Memo・Photo を開く入口、予定を大きく | △ シリーズの TV 仕様では Memo は TV 版を作らない（Web 版をブラウザで）。決めてほしいこと |

決めてほしいことは Theta.Hatch.Series の `progress/tvhome.md`。
