NAS のえいが・しゃしん・ほんも TVhome で（Movie・Photo・Book Hatch の機能の内蔵、その 2）。

- クロスバーに「えいが」「おんがく」「しゃしん」「ほん」：つづきから・棚（共有フォルダの直下。⑧・▶ のフォルダがあればそれ）・ぜんぶ
- **えいが**：mpv で再生（Movie.Hatch と同じく mkv・HEVC・DTS・二か国語の .ts もそのまま）。決定＝一時停止、←→＝10 秒もどる／30 秒すすむ、↑＝音声（二か国語）、↓＝字幕。見たところを覚えて、次は続きから
- **しゃしん**：フォルダの写真をスライドショー（7 秒ごと）。新しい年・日付が先。動画は決定で再生
- **ほん**：PDF と漫画（CBZ・ZIP）をページ送り。テレビの中に落としてから読む（2GB まで、古い順に消す）。読んだページを覚える。EPUB はあとの版
- えいが・しゃしん・ほんは、ホームと別のプロセスで動く（落ちてもホームは落ちない）
- せってい →「NAS」で、種類ごとの共有フォルダ（既定 /video・/music・/photo・/book。実際の名前に合わせる）
- APK は約 28MB（mpv の部品。ARM の 2 種類だけ・圧縮して入れる）
