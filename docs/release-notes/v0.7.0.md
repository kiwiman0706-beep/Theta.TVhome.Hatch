NAS の音楽を TVhome で（Music.Hatch の機能の内蔵、その 1）。

- クロスバーに「おんがく」：つづきから・棚（NAS の音楽のフォルダの直下。▶ のフォルダがあればそれ）・ぜんぶの おんがく
- フォルダをたどって、決定でそこから再生（ぜんぶ さいせい・いちじていし）。曲名はファイル名から
- 再生は裏の別のプロセスで続く（ホームに戻っても鳴る。左上に曲名。リモコンの再生・一時停止ボタンも効く）。再生で落ちてもホームは落ちない
- NAS は DSM の File Station（Movie・Book と同じ）。せってい →「NAS」で URL・ユーザー名・パスワード・音楽のフォルダ。2 段階認証は確認コードを 1 回だけ
- 家の外で NAS に届かないときは、Tailscale をつなぐ（入っていなければ Google Play）案内
- tools/sibling_updates.py：Movie・Music・Book の新しい版を洗い出す（docs/SIBLINGS.md）
