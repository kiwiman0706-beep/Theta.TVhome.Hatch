試作（mock/home.html）のデザインでクロスバーを作り直し、テレビが文鎮にならない仕組みを何重にも。

**ホーム（クロスバー）**
- 上端に横の帯（カレンダー・テレビ・アプリ・せってい、左右はループ）。中身はその下に縦
- 下にさりげなく 2 週間の帯（月曜はじまり・てんき・よてい）。カレンダーを選ぶと 4 週の表に広がり、↓ で日にちを選べる
- 左上：いま再生中のもの（曲名・アルバム・ジャケット・進み・アプリ）。無ければ名前とあいさつ
- 右上：時計・てんき・**ぜんぶのアプリ**・ネット（Wi-Fi・インターネット・Tailscale）
- アプリは「ホームに だす」と決めたものだけ。ぜんぶのアプリで長押し（メニュー）→「★ ホームに だす」
- 操作しないと 5 秒で薄く、25 秒でメニューが消える（いちばん上で「戻る」でもすぐ）。なにかキーで戻る

**文鎮にしない仕組み**
1. 落ちる・固まる（8 秒応えない）が 5 分に 3 回続いたら、次はホームの代わりにレスキュー画面（別のプロセス・素の部品だけ）
2. リモコンの「戻る」を すばやく 7 回で、いつでもレスキュー画面（子どもモードで番号があれば番号を聞く）
3. テレビのアプリ一覧に「TVhome のレスキュー」（純正のホームからも開ける）
4. レスキュー画面：いつもの（純正の）ホームを開く・既定のホームを選び直す・セーフモード・開き直す・Android の設定
5. セーフモード：ネット・動き・自動の更新を止める
6. 最近落ちた・固まったときは、自動の更新をしない
7. ADB：`OPEN --es screen rescue｜safe｜stock`、dumpsys に純正のホームと不具合の記録
8. 純正のホームは消さない・止めない（docs/ADB.md §6）。このアプリを消せば純正のホームに戻る
