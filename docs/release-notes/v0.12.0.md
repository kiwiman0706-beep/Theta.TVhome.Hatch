声で予定・やることを入れる：「きく」で頼むと、確認してから Google カレンダー・ToDo リストに入れる。

- 「あしたの 3じに はいしゃの よてい いれて」「ぎゅうにゅうを かう を やることに」のように、こえ か もじで
- Gemini が中身（名前・日付・時刻・場所）を決め、「これで いい？」の画面を出す。「はい」を押したときだけ入れる
- 予定は家族のアカウントのメインのカレンダー、やることは いつもの ToDo リスト
- 初めて入れるときだけ、Google の許可の画面が出る（書く許可。読む許可とは別）
- キッズでは入れない
- Google Cloud で **Google Tasks API** を有効にする（docs/GOOGLE_ACCOUNT.md）
