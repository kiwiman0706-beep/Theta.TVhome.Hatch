- **ちずで さがす**：Gemini が Google マップで、天気の場所の近くを調べる。場所の一覧（決定で Google マップ）
- **がぞうを さがす**：Google 画像検索をブラウザで開く（テレビにブラウザが要る）
- 子どもモードでは、やさしく・ひらがな多めに答える
