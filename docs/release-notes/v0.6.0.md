予定を Google カレンダーの API で読むように。

- せってい →「Google カレンダー」で、テレビの Google アカウント（家族の共用アカウント）を 1 回許可するだけ。秘密の URL は要らない
- 出すのは Google カレンダーで「表示」にしているカレンダー。予定の色は Google カレンダーの色
- 許可が切れたら（テスト中のプロジェクトは 7 日ほど）、せっていに理由が出る。もう一度押せば許可の画面
- 下準備（テストユーザー・このアプリ用のクライアント・Calendar API）は docs/GOOGLE_ACCOUNT.md
- iCal の非公開アドレスは予備として残す（ADB の SET_SECRET calendar.ics）
