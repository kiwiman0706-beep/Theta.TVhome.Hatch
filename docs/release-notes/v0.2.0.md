ホームの「形」を選べるように（せってい → ホームの形）。

- **キッズ**（はじめはこれ）：キッズホームと同じ、パステルの方眼紙にフチの太いウィンドウ。左に「きょう」（日づけ・天気・よてい）、まんなかに大きなタイル、右のタブは選ぶだけで切り替わる。いろは 7 種（うさぎ・ねこ・くま・きょうりゅう・ユニコーン・うみ・おほしさま）
- **クロスバー**：横にまとまり（きょう・テレビ・すき・アプリ・せってい）、縦に中身。←→ と ↑↓ で選ぶ。色はシリーズのスキン、背景は時刻で色が変わり、ゆっくり波が動く
- **たな**：0.1.0 の横の棚
- ADB：`SET ui.layout`（kids・bar・simple）、`SET kids.theme`
