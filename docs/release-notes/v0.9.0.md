- 一覧の画面：えいがは**ポスター**（作品のフォルダの poster.jpg）、おんがくは**ジャケット**（cover.jpg）、しゃしんは**縮小版**の並び。ほんは一覧のまま
- **作品のまとめ**（Movie.Hatch の名前の決まり）：「題名 (年)」は題名と年、「Season 01」は「シーズン 1」、話は「3 話 サブタイトル」、テレビは「4/7 今回の内容」
- **さいきん ついか**：NAS に新しく入った物（えいがは作品、ほかはフォルダ）
- **さがす**：名前で（ひらがな・カタカナ・全角半角を区別しない）。**こえ**でも（テレビに音声入力があれば）
- 上のボタン：🔍 さがす・🎤 こえで・🆕 さいきん・📁 ぜんぶ・⟳ しらべなおす（・おんがくは ▶ ぜんぶ さいせい・⏯、しゃしんは ▶ スライドショー）
- 索引は NAS をたどって作り、テレビの中に覚える（6 時間ごとに作り直し。深さ 6・2 万件まで）
