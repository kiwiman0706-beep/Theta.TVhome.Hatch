スマホで入れる：長い設定を、スマホで貼り付けてテレビに送る（Theta Link の最初の形）。

- せってい →「📱 スマホで まとめて いれる」（または NAS・Gemini の節の「📱 …を スマホで いれる」）
- テレビに QR コードが出る。スマホのカメラで読むと、テレビが家の LAN の中だけで開く入力ページが開く。貼り付けて「テレビに おくる」
- 入れられるもの：NAS の URL・ユーザー名・パスワード・各共有フォルダ、Gemini の API キー・モデル
- パスワード・キーは空のまま送れば変えない。テレビの中で暗号化して持つ
- 1 回限りの合言葉つき。受け取ったら閉じる。5 分で自動で閉じる。外のサーバーは通さない
- 気をつけること：LAN の中は暗号化していない（HTTP）。家の Wi-Fi で使う
