# 家族の共用 Google アカウントの準備（自宅のテレビ）

自宅の AQUOS（TVhome）は、**家族で共用する Google アカウント**で使う。
シリーズ共通の Google の設定は Theta.Hatch.Series の `spec/THETA_GOOGLE_SETUP.md` が正本。ここはテレビと家族のアカウントに絞った手順。

## 全体像

| どこで | 何に使う | 要るもの | いつ |
| --- | --- | --- | --- |
| ① テレビ本体 | Google Play・YouTube、TVhome の Google の許可 | テレビに家族のアカウントでログイン | 最初に |
| ② Google Cloud（自分のアカウントで） | TVhome が Google カレンダー（あとで Gmail・ToDo・連絡先・ドライブ）を読む許可の下準備 | テストユーザー・このアプリ用のクライアント・API の有効化 | 最初に 1 回 |
| ③ テレビの TVhome | 予定を出す | せってい →「Google カレンダー」で家族のアカウントを許可 | ①②のあと |

---

## ① テレビに家族のアカウントを入れる

1. テレビの 設定 → アカウントとログイン（機種によっては「アカウント」）→ アカウントを追加
2. テレビに出るコードを、スマホかパソコンで開いて家族のアカウントでログインする（その場でパスワードを打つより楽）
3. いま自分のアカウントが入っていれば：
   - 残す：Play ストアで入れたアプリはそのまま。アカウントを切り替えて使える（TVhome の許可の画面では、家族のアカウントを選ぶ）
   - 消す：同じ画面で自分のアカウントを選んで「削除」
4. **子どもが買い物をしないように**：Play ストア → 設定 → 購入時の認証 →「このデバイスで Google Play から購入するときは常に」

## ② Google Cloud の下準備（自分のアカウントで、1 回だけ）

**Google Cloud にログインするのは、シリーズのプロジェクトを作った自分のアカウント**（家族のアカウントでログインする必要はない）。
画面は https://console.cloud.google.com/ 、上のプロジェクト選択がシリーズのプロジェクト（Meishi で作ったもの。`spec/THETA_GOOGLE_SETUP.md`）になっていることを確かめる。

1. **テストユーザーに家族のアカウントを足す**（プロジェクトに 1 回。シリーズの全アプリに効く）
   Google Auth Platform →「対象」→「テストユーザー」→ 家族のアカウントのメールアドレスを追加
2. **このアプリ用の Android の OAuth クライアント**（TVhome に 1 回）
   Google Auth Platform →「クライアント」→「クライアントを作成」
   - 種類：Android
   - 名前：`Theta TVhome Hatch Android`
   - パッケージ名：`app.thetahatch.tvhome`
   - SHA-1：`A1:13:EA:34:83:60:56:32:E7:F5:94:4E:4E:8C:20:55:DD:AE:28:BA`（シリーズ共通の鍵。Releases の APK はこの鍵で署名している）
3. **API を有効にする**（「API とサービス」→「ライブラリ」。プロジェクトに 1 回）

   | API | TVhome で使う | いま |
   | --- | --- | --- |
   | **Google Calendar API** | 予定（0.6.0〜） | **要る**（シリーズで有効かは要確認） |
   | Gmail API | メール（これから） | あとで |
   | Google Tasks API | やること（これから） | あとで |
   | Google People API | れんらくさき（これから） | あとで |
   | Google Drive API | ドライブ（これから） | 有効 |

4. （任意）Google Auth Platform →「データアクセス」に `.../auth/calendar.readonly` を足すと、許可の画面の説明が正しくなる（無くても動く）

反映に数分かかることがある。

## ③ テレビで予定をつなぐ

1. TVhome → せってい →「Google カレンダー」を押す
2. 許可の画面で**家族のアカウント**を選び、「このアプリは Google で確認されていません」→「続行」→「許可」
   （自分たちで作ったテスト中のアプリなので、確認されていないのは正しい）
3. ホームの下の帯とカレンダーに予定が出る
   - 出るのは、家族のアカウントの Google カレンダーで「表示」にしている（左の一覧でチェックが付いている）カレンダー。祝日も「日本の祝日」を表示にしていれば出る
   - 家族の誰かの個人のカレンダーも出したいとき：その人が自分のカレンダーを家族のアカウントに共有し、家族のアカウントの Google カレンダーで表示にする
   - 予定の色は Google カレンダーの色
4. うまくいかないとき（せっていの「Google カレンダー」の下に理由が出る）
   - 「Calendar API を有効にしてください」→ ②-3
   - 許可の画面で何も起きずに戻る → ②-1（テストユーザー）か ②-2（パッケージ名・SHA-1）の違い
   - 「許可が要ります」→ テスト中のプロジェクトは許可が 7 日ほどで切れることがある。せってい →「Google カレンダー」をもう一度押す

## 予備：iCal の非公開アドレス（ふつうは要らない）

②③ができないときだけ。Google カレンダーの 設定 → カレンダーの統合 →「iCal 形式の非公開アドレス」を 1 行 1 つで `calendar.txt` に書き、ADB の `SET_SECRET calendar.ics`（`docs/ADB.md` §5）で入れる。「Google カレンダー」につないでいるときは使わない。
非公開アドレスは「知っている人なら誰でも予定を読める」URL なので、チャット・Git に貼らない。

## 関係する決まり

- Netflix は、大人のプロフィールにプロフィールロック（暗証番号）を付けると、子どもは自分のプロフィールしか入れない
- Google の許可（トークン）は Google Play 開発者サービスがテレビの中で持つ。TVhome もこのリポジトリも、パスワードや鍵を持たない
